# Libera

Libera is the intake and proposal layer.

The name is a portmanteau of libra and liber: balance plus freedom, with liber also carrying the root sense behind library.

Libera owns what was previously called the facilitator protocol.

## Role

Libera converts source material into governed candidate context objects.

It proposes; it does not store canonical state.

## Chain

Source -> Candidate Origin -> Origin -> WorkItem -> ExecutionProjection / MeaningProjection -> Requirement -> Surface -> Outcome -> Memory

## Keeper

Libera proposes. Corus coordinates. Facia prioritizes. Timpos remembers.
