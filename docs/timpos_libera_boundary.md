# Timpos / Libera / Corus Boundary

## Keeper

```text
Libera defines the address.
Timpos records the change.
Corus derives coordination.
Fasia renders meaning.
```

## Libera owns

```text
workstream paths
allowed local values
execution/governance taxonomy
path validation
```

Libera does not record observations or derive coordination state.

## Timpos owns

```text
locator registry
timpos
moments
replay
diff
```

Timpos does not interpret meaning, assign owners, coordinate teams, or render surfaces.

## Corus owns

```text
objectives
contracts
reducers
coordination_state
next_actions
role_attention
```

Corus consumes Libera paths and Timpos moments. It derives coordination state from replayed workstream state.

## Fasia owns

```text
faces
surfaces
claims/evidence presentation
role-specific meaning
```

Fasia consumes coordination state. It should not mutate the coordination state directly.
