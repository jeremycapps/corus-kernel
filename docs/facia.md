# Facia

Facia is the surface and priority layer.

Facia consumes coordinated context state from Corus and renders usable faces: why, claims, priorities, and next actions.

Facia is intentionally separate from Libera. Libera proposes candidate context from source material. Facia renders from admitted context state.

## Keeper

Libera proposes. Corus coordinates. Facia prioritizes. Timpos remembers.
